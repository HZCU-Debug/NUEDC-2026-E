# BMI270（IMU660RA）姿态积分参考

> 来源：Bosch Sensortec《BMI270 Datasheet》BST-BMI270-DS000-06，共 150 页  
> 用途：驱动配置、原始数据换算、板级校准与姿态积分

BMI270 是三轴加速度计与三轴陀螺仪组合芯片。芯片带运动识别功能和外部传感器辅助接口，但不直接输出姿态四元数，姿态融合算法需运行在主控上。

## 关键参数

数据手册第 12~15 页给出的主要参数如下。

| 项目 | 数值 |
|---|---|
| 加速度计量程 | ±2 / ±4 / ±8 / ±16 g |
| 加速度计灵敏度 | 16384 / 8192 / 4096 / 2048 LSB/g |
| 陀螺仪量程 | ±125 / ±250 / ±500 / ±1000 / ±2000 dps |
| 陀螺仪灵敏度 | 262.144 / 131.072 / 65.536 / 32.768 / 16.384 LSB/dps |
| 加速度计灵敏度误差 | ±0.4 % |
| 加速度计零偏 | ±20 mg |
| 陀螺仪灵敏度误差 | ±2 %，CRT 后典型 ±0.4 % |
| 陀螺仪零偏 | ±0.5 dps |
| 陀螺仪灵敏度温漂 | 0.02 %/K |
| 陀螺仪零偏温漂 | ±0.015 dps/K |
| 陀螺仪噪声密度 | 高性能 7、普通 10 mdps/√Hz |
| 工作温度 | -40~+85 °C |

加速度计 ODR 为 0.78 Hz~1.6 kHz，陀螺仪普通/高性能模式 ODR 为 25 Hz~6.4 kHz。姿态控制可优先从加速度计 100 或 200 Hz、陀螺仪 200 或 400 Hz 开始配置。

## 原始数据换算

六轴输出为 16 位二进制补码。

```text
accel_g = raw_accel / accel_sensitivity_lsb_per_g
gyro_dps = raw_gyro / gyro_sensitivity_lsb_per_dps
gyro_rad_s = gyro_dps * pi / 180
```

数据手册中的陀螺仪灵敏度误差在 CRT 前可达 ±2 %。这类比例误差不会表现为静止零偏，却会让积分角度按比例偏大或偏小，因此只做静止零偏校准并不够。

## 初始化要求

BMI270 上电后必须加载 Bosch 提供的约 8 KB configuration file，基本顺序如下：

1. 禁用 advanced power save，等待至少 450 µs
2. 向 `INIT_CTRL`（59h）写 00h
3. 将配置数据从 `INIT_DATA`（5Eh）开始分块写入
4. 向 `INIT_CTRL` 写 01h 完成初始化
5. 检查内部状态，再配置六轴量程、ODR 与电源状态

配置文件应直接使用 Bosch 官方驱动附带的数据，不应根据手册自行拼装。

## 标定机制

BMI270 提供三类与姿态积分直接相关的硬件补偿能力：

- FOC（Fast Offset Compensation）：静止条件下半自动估计加速度计和陀螺仪零偏
- IOC（In-use Offset Compensation）：运行中自动更新陀螺仪零偏，启用前应核对使用场景和静止判定条件
- CRT（Component ReTrimming）：芯片静止时重新标定陀螺仪灵敏度，把典型灵敏度误差从 ±2 % 降到 ±0.4 %

加速度计偏移寄存器分辨率为 3.9 mg/LSB，范围 ±0.5 g。陀螺仪偏移字段为 10 位补码，分辨率 61 mdps/LSB，范围 ±31 dps。偏移和 CRT 结果可写入 NVM，但 NVM 写入次数有限，不应在每次开机时写入。

执行 CRT 时芯片必须保持静止，建议在实际工作温度附近执行。检测到运动时 CRT 会中止，并在状态寄存器中报告错误。

## 姿态积分建议

- 首次装板后执行一次 CRT，并保存结果；日常上电只做短时静止零偏估计
- 使用高性能陀螺模式降低噪声，滤波带宽按控制频率选择，带宽过高只会引入更多噪声
- 使用传感器时间戳或主控单调时钟计算 `dt`
- 利用加速度计修正 roll/pitch；动态加速度较大时降低加速度计修正权重
- 六轴融合不能消除 yaw 长期漂移，绝对航向需要外部参考
- 归一化每次更新后的四元数

## 驱动识别信息

| 项目 | 值 |
|---|---|
| I2C 7 位地址 | 0x68 或 0x69，由 SDO 决定 |
| `CHIP_ID`（00h） | 0x24 |
| 加速度计输出 | `DATA_8`（0Ch）~ `DATA_13`（11h） |
| 陀螺仪输出 | `DATA_14`（12h）~ `DATA_19`（17h） |
| `INIT_CTRL` | 59h |
| `INIT_DATA` | 5Eh |

## 上电检查

1. 读取 `CHIP_ID`，确认返回 0x24
2. 完整加载官方配置文件并检查初始化状态
3. 配置量程、ODR、滤波器和电源模式
4. 静止检查陀螺均值和加速度模长
5. 应用零偏、CRT 灵敏度补偿后再启动四元数积分
