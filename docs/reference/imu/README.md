## 三款芯片横向对比

| 项目 | BMI270 | LSM6DSR | LSM6DSV16X |
|---|---|---|---|
| 加速度计量程 | ±2/4/8/16 g | ±2/4/8/16 g | ±2/4/8/16 g |
| 陀螺仪量程 | ±125~±2000 dps | ±125~±4000 dps | ±125~±4000 dps |
| 陀螺仪 ODR 上限 | 6.4 kHz | 6667 Hz | 7.68 kHz |
| 陀螺零偏（出厂标定后） | ±0.5 dps（含焊后全寿命） | ±1 dps | ±1 dps |
| 陀螺零偏温漂 | ±0.015 dps/K | ±0.005 dps/°C | ±0.006 dps/°C |
| 陀螺噪声密度（高性能模式） | 7 mdps/√Hz | 5 mdps/√Hz | 2.8 mdps/√Hz |
| 陀螺灵敏度误差 | ±2 %（CRT 后 typ ±0.4 %） | ±1 % | ±0.3 % |
| 片上传感器融合 | 无（融合算法需跑在主机） | 无四元数输出 | SFLP 直接输出四元数/重力向量/陀螺零偏 |
| 片内标定机制 | FOC/IOC 零偏补偿、CRT 灵敏度补偿、NVM 备份 | 启动时自动装载出厂标定寄存器 | 启动时自动装载出厂标定寄存器 |
| 初始化特殊要求 | 上电后必须下载约 8 KB 配置文件 | 无 | 无 |

## 姿态积分选型要点

- 只打算自己做积分（Mahony/Madgwick/EKF）：三款都可，LSM6DSV16X 噪声最低、灵敏度误差最小，积分漂移最小
- 想直接拿到融合后的四元数：只有 LSM6DSV16X（IMU660RC）片内 SFLP 可以直接输出 game rotation vector 四元数、重力向量和陀螺零偏估计
- BMI270 的陀螺灵敏度误差 ±2 % 是三颗里最大的，做长时间角度积分前建议执行一次 CRT 把误差压到 ±0.4 %，否则纯陀螺积分的角度比例误差会非常明显
- 三款的陀螺零偏在出厂时都已 trim 到 ±1 dps 量级，但每次上电静止时重新估一次零偏仍然是必要的，零偏温漂会直接转化为积分漂移
