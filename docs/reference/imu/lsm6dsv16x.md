# LSM6DSV16X（IMU660RC）姿态积分参考

> 来源：ST《LSM6DSV16X》数据手册 DS13510 Rev 4，共 198 页  
> 用途：驱动配置、原始数据积分与片内 SFLP 四元数输出

LSM6DSV16X 是三轴加速度计与三轴陀螺仪组合芯片。与另外两款芯片相比，它额外提供 SFLP（Sensor Fusion Low Power）算法，可直接输出六轴 game rotation vector 四元数、重力向量和估计的陀螺仪零偏。

## 关键参数

数据手册第 12~13 页给出的主要参数如下，测试条件为 `Vdd = 1.8 V`、`T = 25 °C`。

| 项目 | 数值 |
|---|---|
| 加速度计量程 | ±2 / ±4 / ±8 / ±16 g |
| 加速度计灵敏度 | 0.061 / 0.122 / 0.244 / 0.488 mg/LSB |
| 陀螺仪量程 | ±125 / ±250 / ±500 / ±1000 / ±2000 / ±4000 dps |
| 陀螺仪灵敏度 | 4.375 / 8.75 / 17.5 / 35 / 70 / 140 mdps/LSB |
| 陀螺仪灵敏度容差 | ±0.3 %（量程不超过 ±2000 dps） |
| 加速度计零偏 | ±12 mg |
| 陀螺仪零偏 | ±1 dps |
| 陀螺仪灵敏度温漂 | ±0.007 %/°C |
| 陀螺仪零偏温漂 | ±0.006 dps/°C |
| 陀螺仪噪声密度（高性能模式） | 2.8 mdps/√Hz |
| 加速度计噪声密度（高性能模式） | 60 µg/√Hz |
| 工作温度 | -40~+85 °C |

加速度计 ODR 为 1.875~7680 Hz，陀螺仪 ODR 为 7.5~7680 Hz。姿态控制通常可从 240 或 480 Hz 开始配置。

## 原始数据换算

六轴输出为 16 位二进制补码，小端排列，换算方式与 LSM6DSR 相同。

```text
accel_g = raw_accel * accel_sensitivity_mg_per_lsb / 1000
gyro_dps = raw_gyro * gyro_sensitivity_mdps_per_lsb / 1000
gyro_rad_s = gyro_dps * pi / 180
```

若自行实现融合算法，应使用实际采样时间更新四元数，并在每次更新后归一化。该芯片在三款中陀螺仪噪声最低，且 ±2000 dps 以下的灵敏度容差最小。

## SFLP 片内融合

SFLP 使用加速度计与陀螺仪生成：

- game rotation vector，即设备姿态四元数
- gravity vector，即三维重力方向
- gyroscope bias，即三轴陀螺仪零偏估计

启用方式：设置 embedded function page 中 `EMB_FUNC_EN_A`（04h）的 `SFLP_GAME_EN`。需要重新初始化融合状态时，设置 `EMB_FUNC_INIT_A`（66h）的 `SFLP_GAME_INIT`。

SFLP 输出速率由 `SFLP_ODR`（5Eh）配置，可选 15 / 30 / 60 / 120 / 240 / 480 Hz，默认 120 Hz。四元数、重力向量和零偏结果可批量写入 FIFO。

数据手册第 8 页给出的融合性能如下：

| 状态 | yaw | pitch | roll |
|---|---|---|---|
| 静态 | 0.5° / 5 min | 1.5° | 1.5° |
| 低动态 | 0.7° / 5 min | 0.5° | 0.5° |
| 高动态 | 5.9° / 5 min | 1.6° | 1.2° |

标定达到稳态约需 0.8 s，姿态稳定约需 0.7 s。yaw 指标以每 5 分钟的漂移量表示，不是绝对航向精度。

四元数只直接存储 X、Y、Z 分量，每个分量为 IEEE 754 half-precision 16 位浮点数。标量分量按单位四元数约束恢复：

```text
w = sqrt(max(0, 1 - x*x - y*y - z*z))
```

恢复得到的 `w` 取非负分支，因此使用四元数做连续显示或差分前，要处理 `q` 与 `-q` 表示同一姿态的问题。若相邻四元数点积小于 0，可将当前四元数整体取反以保持符号连续。

数据手册给出的 SFLP 航向精度以每 5 分钟漂移表示，这说明 SFLP 仍是六轴融合，不具备绝对 yaw 观测。片内四元数能简化主控计算，但不能消除长期航向漂移。

## 出厂标定与用户校准

- 零偏指标为完成出厂 calibration 后的数值，启动时芯片会装载内部标定信息
- SFLP 会估计并输出陀螺仪零偏，可用于观察融合状态或保存应用层补偿值
- 即使使用 SFLP，也应在上电后给设备一段静止稳定时间
- 安装后的轴向误差、焊接应力和温度变化仍需通过整机校准处理

## 选用 SFLP 还是自行融合

优先使用 SFLP 的场景：主控算力紧张、希望快速获得稳定的 roll/pitch、能够接受 ST 固定的融合行为。

自行融合更合适的场景：需要调整动态加速度抑制、融合外部磁力计或视觉航向、严格控制坐标系和延迟、需要访问滤波器内部状态。

## 驱动识别信息

| 项目 | 值 |
|---|---|
| I2C 7 位地址 | 0x6A 或 0x6B，由 SDO 决定 |
| `WHO_AM_I`（0Fh） | 0x70 |
| 加速度计配置 | `CTRL1`（10h） |
| 陀螺仪配置 | `CTRL2`（11h） |
| SFLP 输出速率 | `SFLP_ODR`（5Eh） |

## 上电检查

1. 读取 `WHO_AM_I`，确认返回 0x70
2. 配置六轴量程、ODR、工作模式和 FIFO
3. 自行融合时，静止估计零偏后再开始积分
4. 使用 SFLP 时，启用算法并等待姿态稳定
5. 检查输出四元数模长接近 1，并验证板级坐标系方向
