# LSM6DSR（IMU660RB）姿态积分参考

> 来源：ST《LSM6DSR》数据手册 DS11976 Rev 2，共 168 页  
> 用途：驱动配置、原始数据换算、零偏处理与姿态积分

LSM6DSR 是三轴加速度计与三轴陀螺仪组合芯片。芯片不直接输出姿态四元数，需由主控使用陀螺仪和加速度计数据完成姿态解算。

## 关键参数

数据手册第 9~10 页给出的主要参数如下，测试条件为 `Vdd = 1.8 V`、`T = 25 °C`。

| 项目 | 数值 |
|---|---|
| 加速度计量程 | ±2 / ±4 / ±8 / ±16 g |
| 加速度计灵敏度 | 0.061 / 0.122 / 0.244 / 0.488 mg/LSB |
| 陀螺仪量程 | ±125 / ±250 / ±500 / ±1000 / ±2000 / ±4000 dps |
| 陀螺仪灵敏度 | 4.375 / 8.75 / 17.5 / 35 / 70 / 140 mdps/LSB |
| 陀螺仪灵敏度容差 | ±1 % |
| 加速度计零偏 | ±10 mg |
| 陀螺仪零偏 | ±1 dps |
| 陀螺仪灵敏度温漂 | ±0.007 %/°C |
| 陀螺仪零偏温漂 | ±0.005 dps/°C |
| 陀螺仪噪声密度（高性能模式） | 5 mdps/√Hz |
| 加速度计噪声密度（高性能模式） | 60 µg/√Hz |
| 工作温度 | -40~+85 °C |

加速度计支持 1.6~6667 Hz ODR，陀螺仪支持 12.5~6667 Hz ODR。姿态控制通常不需要最高 ODR，可根据控制周期选择 208、416 或 833 Hz，避免无意义地增加总线与滤波负担。

## 原始数据换算

六轴输出均为 16 位二进制补码，小端排列。

```text
accel_g = raw_accel * accel_sensitivity_mg_per_lsb / 1000
gyro_dps = raw_gyro * gyro_sensitivity_mdps_per_lsb / 1000
gyro_rad_s = gyro_dps * pi / 180
```

积分前必须把角速度换算为 `rad/s`，并使用实际采样时间 `dt`。仅用配置 ODR 推算固定 `dt` 会把时钟误差和丢样误差累积到角度中，优先使用芯片时间戳或主控单调时钟。

## 出厂标定与用户校准

- 灵敏度和零偏指标是完成出厂 calibration 与 trimming 后的结果
- 芯片启动时会自动装载包含出厂标定值的寄存器，数据手册要求不要修改这些寄存器
- `X_OFS_USR`（73h）、`Y_OFS_USR`（74h）、`Z_OFS_USR`（75h）可补偿加速度计零偏
- 芯片没有供用户写入的陀螺仪零偏寄存器，陀螺仪零偏应在主控中扣除

出厂标定不能替代板级校准。焊接应力、安装方向和工作温度都会改变实际偏差。建议每次上电静止采样一段时间，取三轴陀螺平均值作为当前零偏；需要较长时间稳定运行时，再建立零偏随温度变化的补偿表。

## 姿态积分建议

- 纯陀螺积分会持续漂移，应使用加速度计重力方向修正 roll 和 pitch
- 六轴 IMU 没有绝对航向参考，静止时也无法从重力观测 yaw，yaw 漂移只能通过外部磁力计、视觉或其他航向参考约束
- 四元数更新后应归一化，避免浮点误差破坏单位四元数约束
- 快速旋转场景应留足量程余量；一般车模姿态可从 ±1000 或 ±2000 dps 开始调试
- FIFO 可同时保存六轴数据和时间戳，适合降低读取抖动并保持采样时序

## 驱动识别信息

| 项目 | 值 |
|---|---|
| I2C 7 位地址 | 0x6A 或 0x6B，由 SDO 决定 |
| `WHO_AM_I`（0Fh） | 0x6B |
| 陀螺仪输出 | 22h~27h |
| 加速度计输出 | 28h~2Dh |
| 加速度计配置 | `CTRL1_XL`（10h） |
| 陀螺仪配置 | `CTRL2_G`（11h） |

## 上电检查

1. 读取 `WHO_AM_I`，确认返回 0x6B
2. 配置量程、ODR 和滤波器
3. 芯片保持静止，检查三轴陀螺均值是否落在合理范围
4. 检查加速度计合成模长是否接近 1 g
5. 扣除陀螺零偏后再启动四元数积分
