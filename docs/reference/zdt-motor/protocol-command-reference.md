# Emm_V5.0 通讯协议命令速查

> 配套主文档：[emm-v5.0-driver-manual-rev1.3.md](emm-v5.0-driver-manual-rev1.3.md)  
> 默认示例：设备地址 `01`，校验方式为固定字节 `6B`。

## 帧格式

```text
地址 + 功能码 + 数据 + 校验
```

| 字段 | 说明 |
|---|---|
| 地址 | `01`–`FF`；`00` 为广播 |
| 功能码 | 指令类型 |
| 数据 | 长度由功能码决定 |
| 校验 | 默认 `6B`；也可配置 XOR、CRC-8、Modbus |

## 运动控制

| 功能 | 格式 | 示例 |
|---|---|---|
| 使能 | `ID F3 AB EN SYNC CS` | `01 F3 AB 01 00 6B` |
| 失能 | `ID F3 AB EN SYNC CS` | `01 F3 AB 00 00 6B` |
| 速度模式 | `ID F6 DIR SPD_H SPD_L ACC SYNC CS` | `01 F6 01 05 DC 0A 00 6B` |
| 位置模式 | `ID FD DIR SPD_H SPD_L ACC PUL(4B) ABS SYNC CS` | `01 FD 01 05 DC 00 00 00 7D 00 00 00 6B` |
| 立即停止 | `ID FE 98 SYNC CS` | `01 FE 98 00 6B` |
| 同步触发 | `ID FF 66 CS` | `01 FF 66 6B` |

字段：

- `DIR`：`00=CW`，`01=CCW`。
- `SPD`：2 字节转速，单位 RPM；启用 `S_Vel_IS` 后实际值缩小 10 倍。
- `ACC`：加速度档位；`00` 表示不使用曲线加减速。
- `PUL`：4 字节目标脉冲数。
- `ABS`：`00=相对位置`，`01=绝对位置`。
- `SYNC`：`00=立即执行`，`01=等待同步触发`。

## 回零

| 功能 | 格式 | 示例 |
|---|---|---|
| 设置单圈零点 | `ID 93 88 STORE CS` | `01 93 88 01 6B` |
| 触发回零 | `ID 9A MODE SYNC CS` | `01 9A 00 00 6B` |
| 读取回零状态 | `ID 3B CS` | `01 3B 6B` |
| 修改回零参数 | `ID 4C AE STORE PARAMS CS` | 见主文档 |

回零状态位：`01` 编码器就绪、`02` 校准表就绪、`04` 正在回零、`08` 回零失败。

## 触发动作

| 功能 | 格式 | 示例 |
|---|---|---|
| 编码器校准 | `ID 06 45 CS` | `01 06 45 6B` |
| 当前角度清零 | `ID 0A 6D CS` | `01 0A 6D 6B` |
| 解除堵转保护 | `ID 0E 52 CS` | `01 0E 52 6B` |

## 读取命令

| 功能码 | 内容 | 请求示例 |
|---:|---|---|
| `1F` | 固件版本、硬件版本 | `01 1F 6B` |
| `20` | 相电阻、相电感 | `01 20 6B` |
| `21` | 位置环 PID | `01 21 6B` |
| `24` | 总线电压 | `01 24 6B` |
| `27` | 相电流 | `01 27 6B` |
| `31` | 线性化编码器值 | `01 31 6B` |
| `32` | 输入脉冲数 | `01 32 6B` |
| `33` | 目标位置 | `01 33 6B` |
| `34` | 实时设定目标位置 | `01 34 6B` |
| `35` | 实时转速 | `01 35 6B` |
| `36` | 实时位置 | `01 36 6B` |
| `37` | 位置误差 | `01 37 6B` |
| `3A` | 电机状态位 | `01 3A 6B` |
| `3B` | 回零状态位 | `01 3B 6B` |
| `43 7A` | 系统状态参数集合 | `01 43 7A 6B` |

位置与角度换算：

```text
angle_deg = signed_position × 360 / 65536
```

## 修改参数

| 功能 | 格式 | 示例 |
|---|---|---|
| 任意细分 | `ID 84 8A STORE MSTEP CS` | `01 84 8A 01 07 6B` |
| ID 地址 | `ID AE 4B STORE NEW_ID CS` | `01 AE 4B 01 10 6B` |
| 位置环 PID | `ID 4A C3 STORE PID CS` | 按参数块填写 |
| 输入速度缩放 | `ID 4F 71 STORE FLAG CS` | 对应 `S_Vel_IS` |

## 返回状态

| 返回 | 含义 |
|---|---|
| `ID FUNC 02 CS` | 成功 |
| `ID FUNC E2 CS` | 条件不满足 |
| `ID 00 EE CS` | 帧或参数错误 |
| `ID FD 9F CS` | 位置到位 |

> [!warning]
> 此速查表用于快速定位命令。实际编程时应以主文档的数据长度、符号位和设备固件版本为准。
