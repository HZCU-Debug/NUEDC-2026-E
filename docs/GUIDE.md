# 控制系统备忘录

## 1. 电机编号

四套接线方案使用相同的电机编号：

| 轴 | 电机 ID |
| --- | ---: |
| X | 1 |
| Y | 2 |
| Z | 3 |
| Roll（旋转轴） | 4 |

所有电机串口均设置为 `115200 8N1`。

- 张大头驱动器：通信端口设为 `UART_FUN`
- 正点原子驱动器：使用 TTL 版本和正点原子私有协议

## 2. 接线

接线时首先认清两端：

> 控制板 TX 接电机 RX，电机 TX 接控制板 RX，不能同名相接

所有控制板、电机驱动器和视觉端必须共地。接线和调整插头前应先断电。

### 2.1 ESP32 + 正点原子

四台电机共用控制板发送线，每台电机使用独立返回线。

| 轴 / ID | ESP32 TX → 电机 RX | 电机 TX → ESP32 RX |
| --- | ---: | ---: |
| X / 1 | GPIO26 | GPIO25 |
| Y / 2 | GPIO26 | GPIO13 |
| Z / 3 | GPIO26 | GPIO14 |
| Roll / 4 | GPIO26 | GPIO19 |

### 2.2 ESP32 + 张大头

四台电机共用一组串口线：

| ESP32 | 四台张大头驱动器 |
| --- | --- |
| GPIO26 TX | RX 并联 |
| GPIO25 RX | TX 并联 |
| GND | GND |

### 2.3 ESP32-S3 N16R8 + 正点原子

四台电机共用控制板发送线，每台电机使用独立返回线。

| 轴 / ID | ESP32-S3 TX → 电机 RX | 电机 TX → ESP32-S3 RX |
| --- | ---: | ---: |
| X / 1 | GPIO40 | GPIO41 |
| Y / 2 | GPIO40 | GPIO42 |
| Z / 3 | GPIO40 | GPIO1 |
| Roll / 4 | GPIO40 | GPIO2 |

### 2.4 ESP32-S3 N16R8 + 张大头

四台电机共用一组串口线：

| ESP32-S3 | 四台张大头驱动器 |
| --- | --- |
| GPIO40 TX | RX 并联 |
| GPIO41 RX | TX 并联 |
| GND | GND |

### 2.5 视觉串口

| 控制板 | 控制板 RX ← 视觉端 TX | 控制板 TX → 视觉端 RX |
| --- | ---: | ---: |
| ESP32 | GPIO16 | GPIO17 |
| ESP32-S3 N16R8 | GPIO12 | GPIO13 |

控制板与视觉端必须共地，串口设置为 `115200 8N1`。

### 2.6 蜂鸣器

| 控制板 | 蜂鸣器控制引脚 |
| --- | ---: |
| ESP32 | GPIO4 |
| ESP32-S3 N16R8 | GPIO8 |

蜂鸣器为低电平触发。执行 `Sol 1`、`Sol 2-1` 或 `Sol 2-2` 时，任务完成并回到原点后，蜂鸣器短响约 200 ms。

## 3. 启动与校准

### 3.1 启动

1. 检查电机 ID 和所用接线方案
2. 给控制板、电机驱动器、树莓派和摄像头全部上电
3. 在树莓派的 `vision/` 目录运行 `bash run_rpi.sh <设备名>`，确认启动日志已经加载对应的摄像头参数
4. 使用正点原子电机时，全部设备上电后单独按一次 ESP32 的 Reset
5. 按顺序完成 `Cal Vision`、`Cal Z` 和 `Cal XY`

可用设备名通过 `bash run_rpi.sh --list` 查看。常用配置为 `old_usb` 和
`raspberrypi_a`。视觉端没有对应设备的现场标定文件时，Mode 1～3 不会发送机械坐标。

### 3.2 Cal Vision

1. 将 `105×297 mm` 湖蓝色半张 A4 标定纸对齐并压平
2. 进入 `Cal Vision`，ESP32 第一次发送 Mode 0，视觉端开始采集标定角点
3. 等待视觉端连续两帧角点稳定
4. 按 S3，ESP32 第二次发送 Mode 0，视觉端保存并立即加载当前设备的标定文件
5. 等待设备回到原点，移走蓝色标定纸，再按 S4 返回菜单

更换或移动摄像头、镜头、支架、工作台，修改分辨率、画面旋转或正式相机参数，以及
搬运坐标明显漂移或落点不准时，都需要重新执行 `Cal Vision`。

### 3.3 Cal Z

1. 使用标定板辅助移动 Z 轴到标定位置
2. 按 S3 保存
3. 屏幕显示 `Saved` 后按 S4 返回菜单

### 3.4 Cal XY

1. 使用标定板辅助移动 X、Y 轴到第一个标定位置
2. 按 S3 保存第一个位置
3. 使用标定板辅助移动到对角标定位置
4. 再按一次 S3 保存
5. 屏幕显示 `Saved` 后按 S4 返回菜单

## 4. 按键与菜单

### 4.1 按键

每个人的按键顺序可能都不太一样，要自己摸索一下，不过就是这四个功能。

| 按键 | 功能 |
| --- | --- |
| S1 | 向上选择 |
| S2 | 向下选择 |
| S3 | 进入、确认或保存 |
| S4 | 返回菜单 |

### 4.2 菜单项

| 菜单项 | 用途 |
| --- | --- |
| `Cal Vision` | 视觉坐标标定 |
| `Cal Z` | Z 轴下降位置标定 |
| `Cal XY` | A4 纸面 XY 坐标标定 |
| `Sol 1` | Mode 1，固定四块彩色拼图 |
| `Sol 2-1` | Mode 2，未知纯色或白色碎片 |
| `Sol 2-2` | Mode 3，不规则扑克牌碎片 |
| `Home` | 让各运动轴返回启动时的零点 |
| `Test` | 配合上位机进行单轴电机测试 |
| `Mock` | 使用模拟数据调试搬运流程 |

## 5. 报错排查

### 5.1 电机轴报错

看到 `Motor X error`、`Motor Y error`、`Motor Z error` 或 `Motor R error` 时，首先检查报错轴的 TX、RX 是否接对：

1. 确认控制板 TX 接电机 RX
2. 确认电机 TX 接控制板 RX
3. 确认插头没有松动、接触不良或接错轴
4. 确认控制板与驱动器共地
5. 确认驱动器已经上电
6. 确认电机 ID、波特率和通信协议
7. **使用正点原子电机时，全部上电后再次按 ESP32 Reset**

正点原子使用独立返回线，优先检查报错轴对应的 RX 引脚。张大头使用共享串口，除报错轴的插头和 ID 外，还要检查整条共享 TX、RX 线路。

| 屏幕报错 | 首先检查 |
| --- | --- |
| `Motor X error` | X 轴（ID 1）的 TX、RX 接线 |
| `Motor Y error` | Y 轴（ID 2）的 TX、RX 接线 |
| `Motor Z error` | Z 轴（ID 3）的 TX、RX 接线 |
| `Motor R error` | Roll 轴（ID 4）的 TX、RX 接线 |
| `Read error`（Cal Z） | Z 轴的 TX、RX 接线 |
| `Read error`（Cal XY） | X、Y 轴的 TX、RX 接线 |

### 5.2 视觉通信报错

看到 `Vision UART error`、`Link error` 或 `Mode send failed` 时：

1. 检查控制板 TX 是否接视觉端 RX
2. 检查视觉端 TX 是否接控制板 RX
3. 检查控制板与视觉端是否共地
4. 检查视觉程序是否已经启动
5. 检查视觉端启动日志中的串口设备和波特率是否为实际接线配置
6. 检查终端是否出现 `READY FOR NEXT ESP32 MODE`

看到 `Waiting vision` 时，视觉端会先等待连续两帧几何稳定并自动求解。求解失败会重新
采集，默认最多等待 90 秒后发送期间得到的最佳安全方案；标定或抓取坐标不可信时会继续
等待，不会发送坐标。

ESP32 按 S4 只会停止本机动作和重传，不会向视觉端发送 `0xFF` 取消消息。如果在视觉端
仍处于标定、求解或发送状态时退出菜单，重新执行任务前应重启视觉程序。

### 5.3 其他报错

| 屏幕报错 | 处理方法 |
| --- | --- |
| `Not calibrated` | 重新执行 `Cal Z` 和 `Cal XY` |
| `Storage error` | 重新进行该项标定；仍然报错时重启控制板后再试 |
| `Invalid or storage` | 确认两次 XY 标定位置不同，再重新标定 |
| `Return failed` | 按电机轴报错流程检查四台电机的 TX、RX 接线 |
| `X/Y/Z/R query timeout` | 检查屏幕所示轴的 TX、RX 接线 |
